# Informe Etapa 2 · Ingeniería de Software

- `Informe_Etapa2_SGR.docx` / `.pdf`: informe final sobre la plantilla INACAP.
- `generar_informe.py` + `contenido.py`: generan el informe (`python docs/informe_etapa2/generar_informe.py`).
- `diagramas/*.puml`: fuentes PlantUML de los diagramas UML y wireframes; `imagenes/`: diagramas renderizados y capturas del prototipo.

Para regenerar los diagramas: `java -jar plantuml.jar -charset UTF-8 -tpng -o ../imagenes docs/informe_etapa2/diagramas/*.puml`.
Antes de entregar, completar en Word la portada (sección, docente e integrantes) y, si cambia el contenido, actualizar el índice (clic derecho → Actualizar campos).
