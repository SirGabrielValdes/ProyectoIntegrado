# Tablero Kanban de la Etapa 3 (GitHub Projects)

Las tarjetas de esta entrega están creadas como *issues* del repositorio, con las etiquetas `etapa-3` y su categoría (`correcciones`, `transaccional`, `reglas-matriz`, `calidad`).

## Crear el tablero (una sola vez, unos 5 minutos)

1. En GitHub, abra el repositorio → pestaña **Projects** → **Link a project** → **New project**.
2. Elija la plantilla **Board** y póngale de nombre «SGR · Etapa 3».
3. Renombre o cree las columnas, en este orden: **Por hacer**, **En curso**, **En revisión** y **Terminado**. Para hacerlo, use el menú «…» de cada columna o edite el campo *Status* en *Settings → Fields → Status*.
4. Agregue las tarjetas: haga clic en **+ Add item** al pie de «Por hacer», escriba `#` y elija los issues, o pegue la búsqueda `is:issue label:etapa-3` en *Add items from repository*.
5. Mueva cada tarjeta arrastrándola según avance la entrega. Para demostrar el uso del tablero conviene que el historial muestre los movimientos.
